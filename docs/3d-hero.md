# 3D 주인공 만들기 (아이를 닮은 캐릭터)

2026-11-09 부모 결정: 아이를 닮은 3D 주인공을 **실사와 피규어의 중간** 느낌으로 만든다. 공개 앱에 넣어도 된다.

## 1. 지금 가진 자료로 되는 것과 안 되는 것

| 자료 | 쓸 수 있는 곳 |
|---|---|
| 얼굴 정면 사진(초록 티셔츠) | 얼굴 닮게 하기에 가장 좋다 |
| 의자에 앉은 전신 사진 | 체형과 옷 느낌 참고. 앉아 있어서 3D 몸 만들기에는 맞지 않다 |
| 영상 2개(5초, 6.6초, 세로) | 얼굴을 앞에서 조금씩 돌려 찍은 것. 표정과 얼굴 각도 참고는 좋지만, 몸 둘레를 한 바퀴 돌며 찍은 게 아니라 **3D 스캔에는 부족하다** |

## 2. 새로 찍으면 좋은 사진 (5분이면 돼요)

1. **서서 찍은 전신 정면:** 밝은 단색 벽 앞에 서요. 팔은 몸에서 조금 떨어지게(A자) 하고, 다리는 어깨너비로 벌려요. 머리부터 발끝까지 다 나오게 찍어요.
2. **같은 자세로 옆모습과 뒷모습:** 여러 장을 넣을 수 있는 서비스에서 쓰면 더 닮아요.
3. **옷:** 몸에 너무 크지 않은, 무늬가 단순한 옷(예: 파란 티셔츠). 앱에서 주인공이 늘 입을 옷이 돼요.
4. **신발:** 신은 채로 찍어요. 맨발이면 3D도 맨발이 돼요.

## 3. 3D로 만들기 (사진 → 3D 서비스)

사진 한 장이나 여러 장으로 3D 인물을 만들어 주는 서비스를 쓴다. 후보는 Meshy, Tripo, Hyper3D Rodin이다. 기능과 무료 범위는 자주 바뀌니 시작할 때 확인한다.

- **입력:** 2절의 전신 정면 사진(+ 옆·뒤), 얼굴 정면 사진
- **느낌:** 실사와 피규어의 중간. 서비스에 스타일 고르기가 있으면 "stylized" 또는 "figurine"에 가까운 것을 고른다. 글로 적는 칸이 있으면 "실사와 장난감 피규어의 중간, 부드러운 얼굴, 큰 눈은 아님"처럼 적는다.
- **뼈대(리깅):** 사람 모양 자동 뼈대를 넣는다. 동작 몇 개를 같이 받는다.
  - 서 있기(숨쉬기)
  - 손 흔들기
  - 점프
  - 브이 포즈(사진 속 아이의 브이를 쓰고 싶다. 없으면 승리 포즈)
- **받을 파일:** GLB 한 파일(뼈대와 동작 포함). 면 수 2만~5만, 텍스처 1024~2048px이면 태블릿에서 부드럽게 돈다.
- **넣을 곳:** `assets/hero/hero.glb`에 두면 앱에 넣는다. 크면 줄이는 것은 제가 한다.

서비스의 API 열쇠를 주시면, 제가 스크립트로 사진을 보내 3D를 받는 것까지 할 수도 있다. 열쇠는 git에 넣지 않는 파일에 둔다.

## 4. 앱에 넣는 계획

- **그리는 도구:** 3D 파일을 그리려면 three.js 라이브러리가 필요하다. 새 라이브러리이므로 넣기 전에 부모 허락을 받는다. 앱이 1MB 안팎 커진다.
- **지도:** "지금 여기" 섬 위에 주인공이 서 있다. 누르면 손을 흔든다.
- **풀기 화면:** 큐브 선생님 옆에 서 있다.
  - 한 번에 맞히면 브이 포즈를 한다.
  - 배지를 받으면 점프한다.
  - 틀려도 실망하는 동작은 하지 않는다.
- **꾸미기:** 배지로 연 모자, 선글라스 같은 것을 주인공에게도 입힐 수 있게 한다(나중).
- **블록 세상과 어울리게:** 땅에 블록 그림자를 깔고, 조명은 무대와 같은 하늘색 빛으로 맞춘다.

## 5. 실제로 만든 방법 (2026-11-12)

무료 도구만 썼다(Hugging Face TRELLIS + Mixamo). 부모 허락으로 아이를 닮은 모델이 git과 배포물에 들어간다(`src/content/hero/`). 원본 영상·장면·FBX는 `assets/hero/`(git 제외)에 둔다.

1. **찍기:** 팔을 옆으로 45도 넘게 벌린 A자 자세로 서서 한 바퀴 돈다(겨드랑이 아래로 배경이 보이게). 팔이 몸에 붙은 영상으로 만들면 팔을 들 때 겨드랑이가 찢어진다(첫 영상에서 겪음).
2. **장면 고르기:** `node scripts/hero-frames.mjs <영상> sheet:0.5` 로 0.5초마다 보고, `node scripts/hero-frames.mjs <영상> 6.3!,3.8!,9.3!` 처럼 그 시각 그대로 뽑는다.
   - 손끝이 화면 안에 다 들어온 장면만 쓴다. 정면, 뒤, 비스듬한 뒤 세 장이면 된다.
   - 아이 옆에 붙은 물건(가방, 옷걸이)은 바닥·벽 색으로 덮는다. TRELLIS 배경 지우기가 함께 남기기 때문이다.
3. **3D:** TRELLIS(Multiple Images)에 올려 GLB를 받는다. 무료 사용량은 로그인해야 넉넉하다.
4. **다듬기:** GLB를 `assets/hero/hero-raw.glb`에 두고 `node scripts/hero-prep.mjs`를 돌린다. 떠 있는 조각을 지우고, Mixamo에 올릴 `assets/hero/mixamo/hero.zip`을 만든다.
5. **뼈대·동작:** Mixamo에 hero.zip을 올리고 표시(턱·손목·팔꿈치·무릎·사타구니)를 놓는다. 동작을 FBX로 받아 `assets/hero/anim/`에 둔다.
   - 쓰러지기: defeated.fbx
   - 서 있기: idle.fbx
   - 춤: dance-*.fbx
   - 하품: yawn.fbx
   - 성벽이 깎일 때 또 하나: hurt-spat.fbx, hurt-injured.fbx
6. **묶기:** `node scripts/hero-pack.mjs` → `src/content/hero/hero.json`(뼈대·메시·동작, 1초 20장면, 회전은 16비트)과 `hero.webp`(텍스처).
   - 앱은 모델 로더 없이 `src/ui/hero-model.js`로 조립한다. GLTFLoader 같은 로더 안의 네트워크 코드가 배포물에 들어가지 않게 하려는 것이다.
   - three.js 셰이더 주석의 논문 주소는 빌드 때 지운다(`vite.config.js`).

**성 지키기에서(src/ui/hero-view.js):** 주인공은 성 옆 조금 높은 땅에서 싸움을 구경한다.
- 평소에는 서 있다. 15초 동안 아무 일이 없으면 하품한다.
- 몬스터를 무찌르면 춤 하나를 차례대로 춘다. 게임과 같은 카메라로 재어 몸이 캔버스 밖으로 나가 잘리는 동작은 넣지 않는다(hero-pack이 재서 뺀다. 2026-11-12에는 Hip Hop Dancing (1)이 빠졌다. 춤은 Hip Hop Dancing, Silly Dancing 두 개, Hip Hop Dancing (2), Chicken Dance 다섯 가지). 이미 춤추는 중이면 하던 춤을 그대로 이어 간다.
- 성벽이 깎이면 고개를 떨구거나(defeated) 얼굴에 뭔가 맞은 듯 움찔하거나(hurt2, "Spat In Face") 아파한다(hurt3, "Injured Hurting Idle"). 셋이 돌아가며 나온다.
- WebGL이 안 되는 기기에서는 주인공 없이 게임만 한다.
